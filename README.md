# 📖 Overview

The **Online Tekken Tournament Management System** is a web-based application built to streamline the management of Tekken tournaments.

The project focuses on organizing tournament data through a well-structured relational database while providing an interface for managing players, tournaments, registrations, matches, and rankings.

It was developed as a database-focused academic project while following modern web development practices.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/smoinx/Online-Tekken-Tournamnet-System.git
```

## Navigate to the project

```bash
cd Online-Tekken-Tournamnet-System
```

## Install dependencies

```bash
npm install
```

## Start the application

```bash
npm run dev
```
